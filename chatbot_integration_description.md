# Descripción de la Integración del Chatbot con OpenAI

Para integrar el chatbot con OpenAI, lo que hice fue básicamente crear un sistema RAG (Retrieval Augmented Generation) que busca información en mi portfolio y luego usa ChatGPT para responder. Primero, saqué todo el texto de los archivos markdown del portfolio y lo dividí en pedacitos más pequeños (chunks). Después, usé la API de embeddings de OpenAI (`text-embedding-3-small`) para convertir cada pedacito de texto en números (vectores) que representan el significado del texto, y los guardé todos en un archivo JSON. Cuando alguien pregunta algo, el sistema convierte la pregunta en números también (genera un embedding de la query) y busca qué pedacitos del portfolio son más parecidos usando una fórmula matemática (similitud coseno).

Cuando alguien hace una pregunta, el sistema busca los 5 pedacitos más parecidos del portfolio (top-k retrieval) y se los manda a GPT-3.5-turbo junto con la pregunta como contexto. Le digo a GPT que solo responda usando esa información del portfolio (mediante un system prompt), así no se inventa cosas. También le agregué una cosa extra: si detecta que preguntan por una práctica específica (usando expresiones regulares para identificar números de práctica), busca primero en esa práctica y le da más importancia (boost de relevancia). Tuve que tener cuidado con los límites de la API de OpenAI (rate limits) porque si hago muchas peticiones muy rápido me bloquean, así que procesé todo en grupos pequeños (batches) con pausas entre medio. Al final, armé un frontend en JavaScript que se conecta con el backend Flask y se integra con MkDocs para que aparezca el chatbot en el sitio.
