## 🎯 **Filosofía del Proyecto**

### **🔄 Misma Metodología, Nuevos Desafíos**
Cada análisis en esta sección parte de una práctica académica específica, pero aplica sus técnicas a datasets de dominios completamente diferentes. No se trata solo de replicar análisis, sino de **adaptar metodologías** a nuevos contextos y descubrir insights únicos.

### **📊 Objetivos Clave**
- **Demostrar versatilidad** en diferentes campos de aplicación
- **Adaptar técnicas** a nuevos tipos de datos y problemas
- **Generar insights** específicos de cada dominio
- **Mostrar capacidad** de transferencia de conocimiento

## 🌿 **Ciencias Naturales**

*De la clasificación de flores a la biodiversidad marina*

### **🍷 Análisis de Especies: Iris → Vinos**
- **Metodología base**: Clasificación multiclase (Práctica Iris)
- **Dataset nuevo**: UCI Wine Dataset (178 muestras, 13 características químicas)
- **Desafío**: Adaptar análisis morfológico a características químicas
- **Insights únicos**: Correlaciones entre composición química y origen geográfico

### **🌡️ Datos Ambientales: Missing Data → Clima**
- **Metodología base**: Detección de datos faltantes (Práctica Ames Housing)
- **Dataset nuevo**: Datos climáticos históricos globales
- **Desafío**: Patrones de missing data en series temporales climáticas
- **Insights únicos**: Impacto de eventos climáticos extremos en la calidad de datos

### **🌱 Biodiversidad: Clasificación → Plantas**
- **Metodología base**: Análisis exploratorio y clasificación
- **Dataset nuevo**: PlantNet Dataset (identificación de especies vegetales)
- **Desafío**: Adaptar técnicas de clasificación a datos de imágenes
- **Insights únicos**: Patrones morfológicos en la identificación automática de plantas

## 💰 **Finanzas y Economía**

*Del análisis de contenido a los mercados financieros*

### **📈 Mercados Financieros: EDA → Cryptomonedas**
- **Metodología base**: Análisis exploratorio temporal (Práctica Netflix)
- **Dataset nuevo**: Datos históricos de Bitcoin, Ethereum y otras criptomonedas
- **Desafío**: Adaptar análisis de tendencias a datos financieros volátiles
- **Insights únicos**: Patrones de volatilidad y correlaciones entre criptomonedas

### **💳 Datos de Crédito: Bias → Scoring**
- **Metodología base**: Detección de sesgos algorítmicos (Práctica Fairlearn)
- **Dataset nuevo**: Datos de scoring crediticio y aprobación de préstamos
- **Desafío**: Identificar sesgos demográficos en decisiones financieras
- **Insights únicos**: Impacto de variables socioeconómicas en el acceso al crédito

### **📊 Análisis Económico: Joins → Datos Económicos**
- **Metodología base**: Integración de múltiples fuentes (Práctica NYC Taxi)
- **Dataset nuevo**: Datos económicos de múltiples países (PIB, inflación, empleo)
- **Desafío**: Integrar indicadores económicos de diferentes fuentes y formatos
- **Insights únicos**: Correlaciones entre indicadores económicos globales
