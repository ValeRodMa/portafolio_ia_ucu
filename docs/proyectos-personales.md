# 🚀 Proyectos Personales

*Exploraciones independientes y análisis avanzados con datasets de mi elección, aplicando técnicas aprendidas y desarrollando nuevas habilidades en ciencia de datos.*

---

## 🎯 **Filosofía de los Proyectos Personales**

A diferencia del trabajo académico estructurado, estos proyectos representan mi **curiosidad personal** y mi **pasión por descubrir patrones ocultos** en datos del mundo real. Cada análisis surge de preguntas genuinas y utiliza las herramientas más avanzadas disponibles.

### **Diferencias Clave con el Portfolio Académico**

| **Aspecto** | **📚 Prácticos** | **🚀 Proyectos Personales** |
|-------------|------------------|------------------------------|
| **Origen** | Asignaciones del curso | Iniciativa personal |
| **Datasets** | Asignados por el profesor | Seleccionados por mí |
| **Metodología** | CRISP-DM estructurado | Exploración libre |
| **Objetivos** | Aprendizaje específico | Descubrimiento y curiosidad |
| **Herramientas** | Python básico + Pandas | Stack completo (ML, APIs, etc.) |
| **Tiempo** | Plazos definidos | Desarrollo continuo |

## 🔮 **Proyectos Futuros**

### **Análisis de Mercados Financieros**
- **Dataset**: Datos históricos de cryptomonedas
- **Técnicas**: Análisis de series temporales, ML predictivo
- **Objetivo**: Identificar patrones de mercado

### **Análisis de Redes Sociales**
- **Dataset**: APIs de Twitter/LinkedIn
- **Técnicas**: NLP, análisis de sentimientos, grafos
- **Objetivo**: Comprender tendencias sociales

### **Análisis de Datos Ambientales**
- **Dataset**: Sensores IoT, datos climáticos
- **Técnicas**: Análisis geoespacial, predicción ambiental

## 🛠️ **Stack Tecnológico Personal**

### **Lenguajes**
- **Python**: Análisis principal
- **R**: Estadística avanzada
- **SQL**: Consultas complejas
- **JavaScript**: Visualizaciones web

- **APIs**: Requests, FastAPI

- **Datos**: PostgreSQL, MongoDB, Redis
